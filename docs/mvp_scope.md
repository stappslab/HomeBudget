# MVP scope

Implemented locally:

- household creation with profile and PIN
- local SQLite storage
- starter categories
- dashboard totals for current month and year to date
- expense amount, category, description, currency and shared flag
- FastAPI health, household, category and expense endpoints
- single-use household access code model and member join endpoint
- author-only expense update and delete rules

Next slice:

- Kivy profile/join workflow and API client integration
- admin approval and role management UI
- category and budget management
- synchronization queue and conflict display
- Android Buildozer configuration
